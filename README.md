# PublicStockAPI

## Structure

- `server/` — Node/Express API
- `client/` — React app (Vite)

## Running

```bash
cd server && npm install && npm run dev   # http://localhost:3001
cd client && npm install && npm run dev   # http://localhost:5173
```
